# Personal Expense Tracker

## About the Project
Personal Expense Tracker is a Java AWT desktop application used to manage daily income and expenses.

## Features
- Add Income
- Add Expenses
- Delete Transactions
- Set Monthly Budget
- View Income and Expense Summary
- View Expense Pie Chart
- Save and Load Expense Records

## Technologies Used
- Java
- Java AWT
- ArrayList
- File Handling

## Project Files
- Main.java
- Expense.java
- ExpenseManager.java

## How to Run
1. Open the project in VS Code.
2. Compile the Java files.
3. Run Main.java.
